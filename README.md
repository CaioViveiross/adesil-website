# 🛒 Ecommerce Adesil Print

Projeto de um ecommerce moderno desenvolvido com foco em **frontend**, permitindo a personalização de etiquetas de forma interativa.

---

## 🚀 Tecnologias

* Next.js
* React
* Tailwind CSS

---

## ✨ Funcionalidades

* Página inicial com produtos e categorias
* Listagem de produtos
* Página de produto com **personalização (texto, cor e fonte)**
* Carrinho de compras (simulado)
* Checkout (simulado)
* Área do cliente (UI)
* Painel administrativo (UI)

---

## 📦 Instalação

```bash
git clone https://github.com/seu-usuario/seu-repo.git
cd seu-repo
npm install
npm run dev
```

Acesse: http://localhost:3000
